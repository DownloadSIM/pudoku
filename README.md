# Pudoku

I want an online Sudoku app that I can simply play online. It just needs to have a sudoku on the landing page, then have a feature for sharing a link for multiplay (people with the same link will play the same sudoku), with settings for difficulties (easy-medium-hard) and for undo/redo/reset. That's it. No complicated sharing, login, etc.
